# 🔐 Login System Pro

# 🔗 Acesse o projeto

👉 https://pedrohenriquedev-lab.github.io/system-login/

Sistema de autenticação completo desenvolvido com HTML, CSS e JavaScript puro.

## 🚀 Funcionalidades

- Cadastro de usuários
- Login com validação
- Dashboard personalizado
- Perfil do usuário
- Controle de sessão (login/logout)
- Proteção de rotas
- Tema Dark/Light
- Armazenamento com localStorage

## 🧠 Tecnologias utilizadas

- HTML5
- CSS3 (com animações e gradientes)
- JavaScript (ES6)
- LocalStorage

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de desenvolvimento web, como:

- Manipulação do DOM
- Estruturação de sistemas
- Lógica de programação
- Experiência do usuário (UX)

## 💻 Como rodar o projeto

1. Baixe o repositório
2. Abra o arquivo `index.html` no navegador

## 📌 Observação

Este projeto simula um sistema real, porém não possui backend ou banco de dados.
